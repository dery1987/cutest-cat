A fluffy ginger kitten with huge bright amber eyes, a slight head tilt, and a ball of pink yarn in its clumsy paws — drawn for make.fun's "Draw the cutest cat" bounty. `main.py` (Python 3.13, standard library only) decodes the 1024×1024 PNG stored in this repository as one line of base64 (`entry.png.b64`) and writes it to the output directory as `entry.png`, deterministically.


## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
